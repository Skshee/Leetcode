| Method               | Purpose                      | Example                  |
| -------------------- | ---------------------------- | ------------------------ |
| `append(x)`          | Add at end                   | `lst.append(5)`          |
| `extend(iterable)`   | Add multiple elements        | `lst.extend([1,2])`      |
| `insert(i,x)`        | Insert at index              | `lst.insert(0,10)`       |
| `pop()`              | Remove & return last element | `lst.pop()`              |
| `pop(i)`             | Remove at index              | `lst.pop(2)`             |
| `remove(x)`          | Remove first occurrence      | `lst.remove(5)`          |
| `clear()`            | Remove all elements          | `lst.clear()`            |
| `index(x)`           | Find index                   | `lst.index(5)`           |
| `count(x)`           | Count occurrences            | `lst.count(5)`           |
| `sort()`             | Sort in place                | `lst.sort()`             |
| `sort(reverse=True)` | Descending sort              | `lst.sort(reverse=True)` |
| `reverse()`          | Reverse list                 | `lst.reverse()`          |
| `copy()`             | Shallow copy                 | `new = lst.copy()`       |
